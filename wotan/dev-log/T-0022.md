# T-0022: Audit the formalization against the LaTeX source archive

**Status**: DONE | **Size**: L
**Phase**: -

## Context

The formalization has so far been interpreted from the rendered paper and extracted
PDF text. Before publication, the author's `arXiv-2309.02332v3.tar.gz` source archive
must be treated as the definitive representation of equation bodies, macro expansion,
cross-references, qualifications, and nearby prose. This audit deliberately waits
until the proof phase reaches a project-control closure checkpoint, so it can assess
the complete claimed coverage rather than a moving subset.

## Acceptance Criteria

- [x] Inspect the archive read-only, inventory its TeX roots, inputs, macros,
  bibliography, and figure dependencies, and record exact provenance and checksum.
- [x] Reconstruct every paper statement claimed by the project from LaTeX source,
  including macro expansion and the qualifying prose needed to interpret it.
- [x] Produce an English source-traceability record mapping paper locations and
  equations to Lean definitions, theorem endpoints, assumptions, and status.
- [x] Compare the source interpretation with the rendered PDF and all formalization
  claims; classify discrepancies by mathematical consequence.
- [x] Create and complete corrective Wotan tasks for every material discrepancy,
  then repeat the affected source and theorem audits before closing this task.
- [x] Run the complete Lean build, proof-gap scan, axiom audit, documentation checks,
  and source-coverage review on the corrected state.
- [x] Do not add the source archive or transient extraction tree to Git.

## Verification Plan

### Hard Endpoints

- [x] Archive checksum and member inventory are recorded and reproducible.
- [x] Every claimed equation/theorem has a source-to-Lean traceability entry.
- [x] `lake build` succeeds after all audit-driven corrections.
- [x] No `sorry` or custom axioms occur in project Lean sources.
- [x] Public theorem endpoints depend only on the accepted standard mathlib axioms.

### Manual Checks

- [x] Macro-expanded formulas agree with the intended signs, indices, domains, and
  quantifiers.
- [x] Nearby prose does not impose assumptions absent from Lean or support claims
  stronger than Lean proves.
- [x] Approximation, modeling, and empirical statements remain visibly distinct from
  exact theorems.

### Risks

- A macro or cross-reference may materially change a formula that looked unambiguous
  in PDF text; the response is corrective proof work, not an explanatory waiver.
- The archive may require unavailable historical TeX packages to compile. Source
  interpretation and comparison can still proceed from the dependency graph and
  macro definitions, while any compilation gap is recorded precisely.

## Approach

Open the archive only after the proof queue reaches closure. Extract it into an
ignored temporary directory, identify the document root and macro environment, and
build a traceability matrix from source statements to public Lean endpoints. Check
the highest-risk formulas first, then all remaining claimed coverage. Any material
finding reopens the affected proof and documentation before the audit is accepted.
