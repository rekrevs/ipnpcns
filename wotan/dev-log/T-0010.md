# T-0010: Derive NNLS contraction from finite Gram spectral bounds

**Status**: DONE | **Size**: L
**Phase**: -

## Context

T-0008 proves deterministic convergence from `BatchLinearContraction`. Derive that
interface from explicit finite Gram/singular-value bounds and clarify the
rank-deficient case behind the paper's step-size discussion.

## Approach

Express the coefficient Gram action directly in the finite coordinate representation
already used by `batchLinearErrorStep`. Prove its quadratic energy identity, then use
explicit lower and upper Rayleigh bounds to control
`‖h - εGh‖² = ‖h‖² - 2ε⟨h,Gh⟩ + ε²‖Gh‖²`. A lower bound on `⟨h,Gh⟩` supplies strictness, while an
upper operator bound controls `‖Gh‖²`. Package the resulting scalar factor as a
`BatchLinearContraction` and instantiate T-0008. Treat a nontrivial Gram kernel
separately: prove that it precludes strict coefficient-space contraction and record
the valid prediction/minimizer-set alternative rather than claiming uniqueness.

## Implementation Notes

- Defined prediction energy and the coefficient Gram action, and proved that the
  latter is exactly multiplication by `X Xᵀ`.
- Proved the quadratic-form identity `⟨h, X Xᵀh⟩ = ‖Xᵀh‖²` and the exact energy
  expansion of one unprojected error step.
- Introduced explicit lower and upper squared singular-value bounds. The upper bound
  is stated on `X`, so applying it to `Xᵀh` gives the needed Gram-action estimate.
- Derived the sharp squared factor
  `1 - ε (2 - ε L) μ` and proved it lies in `[0,1)` when
  `0 < μ ≤ L` and `0 < ε < 2 / L`.
- Instantiated `BatchLinearContraction` and the T-0008 convergence theorem with this
  factor.
- Proved injectivity of `Xᵀ`, equality of predictions for any two NNLS minimizers,
  and coefficient uniqueness in the positive-lower-bound regime.
- Proved that a nonzero kernel direction is fixed by the unprojected error map and
  therefore rules out every strict coefficient-space contraction.

## Obstacles

The paper's rank-deficient deterministic claim cannot use strict contraction on
coefficients. The valid result proved here is that all minimizers have the same
prediction, while kernel directions obstruct `q < 1`. Convergence to the minimizer set
requires a separate averaged/nonexpansive-operator argument and is T-0016.
