## Approach

Start from mathlib's coordinate-free orthogonal-complement and orthogonal-projection
API, because those statements are independent of a matrix representation and are the
actual content used later. Then specialize to finite matrices by treating their
column spaces as ranges of linear maps. Prove the range identity through the adjoint
kernel/range orthogonality route if the matrix API does not expose it directly. For
comparisons, first prove the finite orthonormal-basis average identities; instantiate
trace/Frobenius notation only where it adds a theorem rather than bookkeeping. Any
missing Moore--Penrose representation will be split into a follow-on task while the
intrinsic projector results remain complete.

## Obstacles

Mathlib 4.31 has no Moore--Penrose pseudoinverse implementation. None is needed for
the intrinsic identities or `Col(A Aᵀ) = Col(A)`, so no pseudoinverse axiom was
introduced. Exact formulas written with `A⁺`, including `A A⁺` as the canonical
projector, have been decomposed into T-0015.
