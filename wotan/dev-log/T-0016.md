# T-0016: Prove rank-deficient projected NNLS convergence

**Status**: READY | **Size**: L
**Phase**: -

## Context

T-0010 proves the paper's deterministic step interval under a positive lower
singular-value bound and proves that strict coefficient contraction is impossible in
a nontrivial prediction kernel. The paper also claims convergence to a minimizer when
the minimizer need not be unique.

## Acceptance Criteria

- [ ] Prove averagedness or Fejér monotonicity of the projected gradient map for
  `0 < ε < 2 / L` under an explicit upper spectral bound.
- [ ] Prove asymptotic regularity and convergence, in finite dimension, to some NNLS
  minimizer when the solution set is nonempty.
- [ ] Reuse T-0010's proof that all minimizers have the same prediction.
- [ ] Keep coefficient uniqueness conditional on injectivity/full row rank.
- [ ] Build without `sorry` or custom axioms.
