# T-0021: Bound the exponential occupancy approximation

**Status**: DONE | **Size**: M
**Phase**: -

## Context

T-0013 proved the exact expected collateral occupancy formula but retained the
paper's exponential replacement after equation (30) behind an abstract
`ExponentialOccupancyErrorBound` premise. For `0 < n` and `p ≤ n`, the replacement
can be justified quantitatively from elementary exponential and finite-power bounds.

## Acceptance Criteria

- [x] Prove that the exponential occupancy approximation does not exceed the exact
  occupancy formula when `0 < n` and `p ≤ n`.
- [x] Prove an explicit absolute error bound of `m p² / n` in the same parameter
  regime.
- [x] Instantiate `ExponentialOccupancyErrorBound` with the explicit bound and
  connect it to the exact expected-occupancy theorem.
- [x] Keep zero and invalid parameter cases separate from the valid sparse regime.
- [x] Build without `sorry` or custom axioms.

## Approach

Put `x = p/n`, so `0 ≤ x ≤ 1`. Combine `1 - x ≤ exp(-x)` with the local estimate
`exp(-x) - (1-x) ≤ x²`. Lift both inequalities through the `m`th power using a
finite power-difference estimate on `[0,1]`, rewrite `exp(-m x)` as
`exp(-x)^m`, and scale by `n`.
